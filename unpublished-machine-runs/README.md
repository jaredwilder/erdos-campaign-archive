# Machine runs that weren't published before

Everything here comes from the local working tree and wasn't in any public repository. It's published unfiltered.

- `rapid-fire/`: short proof runs on covering designs, C5-free sets and "siege" exercises.
- `msl-machine/compress/`, `strengthen/`, `dag/`: runs that combined and strengthened already-proved statements for Erdős 289, 479, 936 and others, plus the proof DAG for every problem. The DAG's raw ore is in `msl-ore-estate/dag-ore-2026-09-02`.
- `autonomy-divorce/formalization/`: formalization checks from the autonomy tests.
- `cable-theorems-c1363/`: capacity and degree-budget lemmas for covering case c1363.
- `other/`: every remaining Lean or TeX file that had no public copy, kept at its original path. It includes drafts, failed attempts and files with `sorry`, so check each file before relying on it.
